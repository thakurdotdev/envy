# Architecture

Every module, what it does, and which modules it talks to. Update this file in
the same commit whenever a module is added, removed or changes its
dependencies.

| Module                  | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                | Talks to                                             |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| `packages/shared`       | Product name, shared API error codes, .env parser and writer, client trust rules (pinned keys, versions seen, opening wrapped keys, ADR 0016), client-made UUIDv7 ids                                                                                                                                                                                                                                                                                       | `packages/crypto` (to open wrapped keys)             |
| `packages/crypto`       | Every crypto function: master key (Argon2id), user keys, recovery key, env key wrapping, secrets encryption, fingerprints                                                                                                                                                                                                                                                                                                                                   | libsodium only                                       |
| `apps/api` lib          | Config check at boot, `AppError`, error handler, request ids, redacting logger, rate limiters (sign-in and every write), security headers, auth guard, access checker, pagination                                                                                                                                                                                                                                                                           | Every module                                         |
| `apps/api` auth         | GitHub device and web sign-in, access and refresh tokens, sessions (`/v1/auth/*`, `/v1/me/sessions`)                                                                                                                                                                                                                                                                                                                                                        | users repository, GitHub, Postgres                   |
| `apps/api` users        | Profile, first key setup and replacing the encrypted private key after a key challenge (`/v1/me`, `/v1/me/keys`, ADR 0017)                                                                                                                                                                                                                                                                                                                                  | auth service (guard), Postgres                       |
| `apps/api` projects     | Create (with the four starter environments), list, read, rename, soft delete                                                                                                                                                                                                                                                                                                                                                                                | members, environments, audit repositories            |
| `apps/api` environments | List and create environments, serve the caller's wrapped key, rotate keys                                                                                                                                                                                                                                                                                                                                                                                   | members, audit repositories                          |
| `apps/api` secrets      | Push encrypted versions (with conflict checks), fetch by version, history                                                                                                                                                                                                                                                                                                                                                                                   | environments, audit repositories                     |
| `apps/api` audit        | Append-only log of project and secret actions; admin-only list                                                                                                                                                                                                                                                                                                                                                                                              | Postgres                                             |
| `apps/api` tokens       | Read-only service tokens: create, list, revoke, authenticate `envy_` bearers, describe the current token                                                                                                                                                                                                                                                                                                                                                    | environments, projects, audit repositories           |
| `apps/api` members      | Invites, accept, list (with public keys), grant, role changes, removal with key rotation                                                                                                                                                                                                                                                                                                                                                                    | environments (rotation), users, audit repositories   |
| `apps/cli` commands     | One file per command: login, logout, password and recover (`keys.ts`), init, pull, push, run, set/unset/get, use, members, accept, history/rollback, token, env, doctor, completion, menu                                                                                                                                                                                                                                                                   | cli core, cli ui                                     |
| `apps/cli` core         | Session and token refresh over Eden, keystore, unlock (master password), project link, environment choice, encrypt/decrypt and push/pull, grant and rotation, trust store (`trust.json`: pinned public keys, known projects, newest versions seen; rules in `packages/shared`), every environment key opened or wrapped in `env-keys.ts`, release lookup and download (upgrade), anonymous upgrade count (`analytics.ts`, ADR 0015), clipboard (login code) | `packages/crypto`, `packages/shared`, API types only |
| `apps/cli` ui           | Output, prompts (with non-interactive fallback), keys-only diffs, a fix for every API error code                                                                                                                                                                                                                                                                                                                                                            | `packages/shared`                                    |
| `apps/web` pages        | Public: landing page (`/`) and docs (`/docs`), no API calls. Dashboard (`(app)` group, inside the session): projects (`/projects`), project (environment tabs, secret editor with a table and a .env view, paste or drop a whole .env, history), members, service tokens, audit, devices, invite, login                                                                                                                                                     | web lib, shadcn components                           |
| `apps/web` auth screens | `components/auth/`: sign in, choose a master password, save the recovery key, unlock. Shown by `SessionGate` (in the `(app)` layout's `DashboardFrame`, with the header) until the keys are unlocked                                                                                                                                                                                                                                                        | session, shadcn components                           |
| `apps/web` lib          | API client (in-memory access token, locked refresh), session (unlock, idle lock), browser crypto operations, trust store in browser storage and the key confirmation dialog (ADR 0016), `useLoad` (keeps data on screen while refreshing; in-memory cache of non-secret answers, cleared on lock)                                                                                                                                                           | `packages/crypto`, `packages/shared`, API types only |

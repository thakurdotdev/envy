# Architecture

Every module, what it does, and which modules it talks to. Update this file in
the same commit whenever a module is added, removed or changes its
dependencies.

| Module                  | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Talks to                                             |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| `packages/shared`       | Product name, shared API error codes, .env parser and writer, layer rules (which environments sit under which, merging and separating them, ADR 0018), client trust rules (pinned keys, versions seen, opening wrapped keys, ADR 0016), client-made UUIDv7 ids                                                                                                                                                                                                                                                                                                                                    | `packages/crypto` (to open wrapped keys)             |
| `packages/crypto`       | Every crypto function: master key (Argon2id), user keys, recovery key, env key wrapping, secrets encryption, fingerprints                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | libsodium only                                       |
| `apps/api` lib          | Config check at boot, `AppError`, error handler, request ids, redacting logger, rate limiters (sign-in and every write), security headers, auth guard, access checker (role, and access per environment), pagination                                                                                                                                                                                                                                                                                                                                                                              | Every module                                         |
| `apps/api` auth         | GitHub device and web sign-in, access and refresh tokens, sessions (`/v1/auth/*`, `/v1/me/sessions`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | users repository, GitHub, Postgres                   |
| `apps/api` users        | Profile, first key setup and replacing the encrypted private key after a key challenge (`/v1/me`, `/v1/me/keys`, ADR 0017)                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | auth service (guard), Postgres                       |
| `apps/api` projects     | Create (with the four starter environments), list, read, rename, delete (restorable for 30 days), restore, and a daily purge of projects deleted longer ago (`purge.ts`, started by `index.ts`)                                                                                                                                                                                                                                                                                                                                                                                                   | members, environments, audit repositories            |
| `apps/api` environments | List and create environments (a new stage goes to every app too), serve the caller's wrapped key, rotate keys, the layers under an environment                                                                                                                                                                                                                                                                                                                                                                                                                                                    | members, audit repositories                          |
| `apps/api` apps         | Apps in a monorepo (ADR 0018): list, create (one environment per root stage), remove (revokes its tokens)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | environments, tokens, audit repositories             |
| `apps/api` secrets      | Push encrypted versions (with conflict checks; several environments all or nothing), fetch by version, history                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | environments, audit repositories                     |
| `apps/api` audit        | Append-only log of project and secret actions; admin-only list                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Postgres                                             |
| `apps/api` tokens       | Read-only service tokens: create (with keys for the layers under the environment), list, revoke, authenticate `envy_` bearers, describe the current token and its layers                                                                                                                                                                                                                                                                                                                                                                                                                          | environments, projects, audit repositories           |
| `apps/api` members      | Invites, accept, list (with public keys and access), grant (with access), role changes, access per environment (`access.ts`, `change-access.ts`, ADR 0019), removal with key rotation                                                                                                                                                                                                                                                                                                                                                                                                             | environments (rotation), users, audit repositories   |
| `apps/cli` commands     | One file per command: login, logout, password and recover (`keys.ts`), init (finds monorepo apps), pull, push, run, apps, set/unset/get, use, members, accept, history/rollback, token, env, doctor, completion, menu                                                                                                                                                                                                                                                                                                                                                                             | cli core, cli ui                                     |
| `apps/cli` core         | Session and token refresh over Eden, keystore, unlock (master password), project link (with apps), targets (root or app, from the folder or `--app`), environment choice, layered pulls, workspace folders, `.env` import, app keys (`apps.ts`), encrypt/decrypt and push/pull, grant and rotation, trust store (`trust.json`: pinned public keys, known projects, newest versions seen; rules in `packages/shared`), every environment key opened or wrapped in `env-keys.ts`, release lookup and download (upgrade), anonymous upgrade count (`analytics.ts`, ADR 0015), clipboard (login code) | `packages/crypto`, `packages/shared`, API types only |
| `apps/cli` ui           | Output, prompts (with non-interactive fallback), keys-only diffs, a fix for every API error code                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | `packages/shared`                                    |
| `apps/web` pages        | Public: landing page (`/`) and docs (`/docs`), no API calls. Dashboard (`(app)` group, inside the session): projects (`/projects`), project (app picker for a monorepo, environment tabs, secret editor with a table and a .env view, paste or drop a whole .env, history), members, service tokens, audit, devices, invite, login                                                                                                                                                                                                                                                                | web lib, shadcn components                           |
| `apps/web` auth screens | `components/auth/`: sign in, choose a master password, save the recovery key, unlock. Shown by `SessionGate` (in the `(app)` layout's `DashboardFrame`, with the header) until the keys are unlocked                                                                                                                                                                                                                                                                                                                                                                                              | session, shadcn components                           |
| `apps/web` lib          | API client (in-memory access token, locked refresh), session (unlock, idle lock), browser crypto operations, trust store in browser storage and the key confirmation dialog (ADR 0016), `useLoad` (keeps data on screen while refreshing; in-memory cache of non-secret answers, cleared on lock)                                                                                                                                                                                                                                                                                                 | `packages/crypto`, `packages/shared`, API types only |
